# Project content format

Project metadata is stored in `src/content/projects/` so it can be read during the static build without being published as a public asset.

Each project file uses this format:

```text
Project Title: TESDA E-Assess
Role: Full-Stack Developer
Project Type: Student Project
Year: 2026
Status: Completed
Overview: A short project overview.
Technologies: Next.js, React, TypeScript
Results: A concise description of outcomes.
GitHub Link:
Image Alt: A useful description of the project image.
```

Project images remain in `public/images/projects/<project-folder>/`.
